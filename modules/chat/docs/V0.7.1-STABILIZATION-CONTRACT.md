# EduVigIA Chat V0.7.1 — Stabilization

Baseline: V0.7.0-R1 + HF5, with live PTT and recorded playback validated between two computers.

V0.7.1 changes no end-user feature. It hardens:
- Redis Pub/Sub idle operation;
- Redis reconnect after restart;
- PTT stale-floor cleanup;
- recording/history persistence after API restart;
- PTT 30-second limit and WEBSOCKET_WEBM_OPUS transport;
- school isolation.

Core compose, Core database and Core Redis remain untouched.
